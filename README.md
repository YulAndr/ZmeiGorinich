# In the Footsteps: Exploring the Udege Taiga

*Original title: По следам: в удэгейской тайге*

A 2D narrative-driven adventure game prototype based on the language, folklore, and cultural heritage of the Udege, an Indigenous people of the Russian Far East.

**[Play the prototype on itch.io](https://yulandr.itch.io/udege-forest)**

## Project Overview

This game was developed as part of an undergraduate thesis in Fundamental and Applied Linguistics at Far Eastern Federal University.

The project explored how aspects of Udege language and culture could be represented through a video game. The team drew on dictionaries, folklore collections, and ethnographic studies to develop the game's narrative and cultural content.

The prototype was developed in Unity using C# by a team of three students responsible for programming, artwork, and game design.

## Linguistic and Cultural Content

The game introduces players to aspects of Udege language and culture through its narrative, environment, and character interactions.

The dialogues incorporate selected Udege vocabulary, including greetings and culturally specific terms. Elements of Udege folklore, traditional beliefs, and material culture also form part of the storyline.

The project explores video games as an alternative medium for presenting linguistic and cultural material.

## Story

The protagonist, Aylin, is a second-year university student who sets out on a field expedition to document aspects of Udege language and culture.

Before the expedition, her academic supervisor receives a letter from the daughter of a Udege shaman, accompanied by a mysterious message written in Udege. When her supervisor is unable to accompany her, Aylin travels to the taiga alone.

What begins as an academic expedition turns into an adventure involving the search for a copper mirror known as *toli*.

## Technical Implementation

### Dialogue System

NPC dialogues are implemented using the HeneGames Dialogue System integrated into the Unity project.

Players can initiate conversations by approaching characters and pressing F.

### Contextual Hints and Information Displays

The prototype includes an event-driven system for displaying contextual hints and informational messages.

### Additional Features

- Parallax background scrolling
- Animated user interface elements
- Main menu and exit confirmation
- Audio volume settings stored using Unity PlayerPrefs

## Project Status

The current version is a playable prototype covering the opening section of the planned storyline. It ends when the protagonist reaches a cave intended to serve as an entrance to the afterlife.

Puzzle-solving was part of the original game concept but was not implemented in the current version.

## Third-Party Components

The project uses the HeneGames Dialogue System and Unity TextMesh Pro.
